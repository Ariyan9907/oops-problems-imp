# Smart TV System

## Overview
A Java application demonstrating **Multiple Interface Implementation** by combining multiple capabilities into a Smart TV.

## OOP Concept
- Multiple Interfaces

## Features
- Connect to Wi-Fi
- Play music
- Stream videos
- Independent feature interfaces

## Technologies
- Java
- OOP

## Project Structure
```
src/
├── WiFi.java
├── MusicPlayer.java
├── VideoStreamer.java
├── SmartTV.java
└── Main.java
```

## Learning Outcomes
- Multiple Interface Implementation
- Interface Segregation
- Loose coupling
- Modular application design

# Notification Service

## Overview
A Java application demonstrating **Runtime Polymorphism** through different notification channels.

## OOP Concept
- Runtime Polymorphism
- Method Overriding

## Features
- Email Notification
- SMS Notification
- Push Notification
- Common notification interface

## Technologies
- Java
- OOP

## Project Structure

```
src/
├── Notification.java

├── SMSNotification.java
├── PushNotification.java
└── Main.java
```

- Dynamic Method Dispatch

# House Management System

## Overview
A Java application demonstrating **Composition**, where rooms cannot exist without a house.

## OOP Concept
- Composition

## Features
- Create house
- Add multiple rooms
- Display room details
- Strong ownership relationship

## Technologies
- Java
- OOP

## Project Structure
```
src/
├── House.java
├── Room.java
└── Main.java
```

## Learning Outcomes
- Composition
- Strong HAS-A relationship
- Object lifecycle dependency

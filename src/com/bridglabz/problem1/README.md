# Banking Application

## Overview
A Java application that demonstrates **Encapsulation** by securely managing bank account operations. The account balance cannot be modified directly and all transactions are validated.

## OOP Concept
- Encapsulation

## Features
- Create bank account
- Deposit money
- Withdraw money
- Validate balance before withdrawal
- Display account details

## Technologies
- Java
- OOP

## Project Structure
```
src/
├── Account.java
└── Main.java
```

## Learning Outcomes
- Data hiding
- Getter and Setter methods
- Validation inside class methods
- Secure object design

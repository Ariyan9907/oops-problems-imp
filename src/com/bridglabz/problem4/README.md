# Billing Calculator

## Overview
A Java application demonstrating **Compile-Time Polymorphism** using method overloading for different billing scenarios.

## OOP Concept
- Method Overloading

## Features
- Calculate two items
- Calculate three items
- Integer calculation
- Decimal calculation
- Mixed data type calculation

## Technologies
- Java
- OOP

## Project Structure
```
src/
├── BillingCalculator.java
└── Main.java
```

## Learning Outcomes
- Compile-time polymorphism
- Method signatures
- Overloaded methods

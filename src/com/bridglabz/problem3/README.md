# Vehicle Management System

## Overview
A Java application demonstrating **Inheritance** by managing different vehicle types with shared and specialized behavior.

## OOP Concept
- Inheritance

## Features
- Common vehicle properties
- Car
- Bike
- Truck
- Start and Stop methods
- Display vehicle details

## Technologies
- Java
- OOP

## Project Structure
```
src/
├── Vehicle.java
├── Car.java
├── Bike.java
├── Truck.java
└── Main.java
```

## Learning Outcomes
- Code reuse
- IS-A relationship
- Method inheritance
- Constructor chaining

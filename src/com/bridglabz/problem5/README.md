# Employee Management System

## Overview
A Java application demonstrating **Aggregation** where employees belong to departments while both can exist independently.

## OOP Concept
- Aggregation

## Features
- Create employees
- Create departments
- Assign department
- Transfer employee
- Display employee details

## Technologies
- Java
- OOP

## Project Structure
```
src/
├── Employee.java
├── Department.java
└── Main.java
```

## Learning Outcomes
- HAS-A relationship
- Object association
- Independent object lifecycle

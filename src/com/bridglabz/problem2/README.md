# Payment Processing System

## Overview
A Java application demonstrating **Interface** and **Runtime Polymorphism** by supporting multiple payment methods.

## OOP Concept
- Interface
- Runtime Polymorphism

## Features
- UPI Payment
- Credit Card Payment
- Debit Card Payment
- Net Banking Payment
- Checkout works with any payment type

## Technologies
- Java
- OOP

## Project Structure
```
src/
├── Payment.java
├── UPI.java
├── CreditCard.java
├── DebitCard.java
├── NetBanking.java
├── Checkout.java
└── Main.java
```

## Learning Outcomes
- Programming to interfaces
- Loose coupling
- Runtime polymorphism
- Extensible application design
